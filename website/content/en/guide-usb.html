Before you start

  • A USB stick of 8 GB or more. Everything on it will be erased, so copy anything important off it first.
  • The BioKids ISO ({{ site.iso_name }}) from the download page.
  • Optionally, check its SHA256. A broken download causes strange errors halfway through installing.

Write the stick

Pick the computer you are using now. The easiest tool is balenaEtcher: the same three steps on Windows, macOS and Linux.

macOS

{# Plain step markup here, not m.step: only the Windows path feeds the table of contents and the HowTo data. #}

  1. Download Etcher

    Download the macOS version from etcher.balena.io and drag it to Applications. If macOS asks on first launch, press Open.

  2. Flash in three steps

    Flash from file → the ISO, Select target → the USB stick, then Flash! It asks for your Mac password; that is normal.

  3. Ignore the warning

    When it is done, macOS may say "The disk you attached was not readable by this computer". That is expected: the stick is now made to start a PC. Press Eject.

Linux

  1. Find the stick's name

    Plug the stick in and list the disks in a terminal. Recognise yours by its size (for example sdb, 7.5G).

    {{ m.code('lsblk -d -o NAME,SIZE,MODEL') }}

  2. Write it with dd

    Replace sdX with your stick's name. Picking the wrong disk erases that disk, so look twice.

    {{ m.code('sudo dd if=' ~ site.iso_name ~ ' of=/dev/sdX bs=4M status=progress conv=fsync') }}

    Rather not use a terminal? Etcher works on Linux too, and so does Restore Disk Image in GNOME Disks.

What next?

The stick is ready. Now you start the computer from it:

  • If nothing on the computer needs to be kept: the install guide.
  • If you want to keep Windows: install beside Windows.
  • To try it first, you do not even need the stick: try it in VirtualBox.

Something wrong?

Etcher says "Something went wrong"

It is usually the stick or the file. Check the ISO's SHA256, and try another USB port or another stick. Some cheap sticks say 8 GB but hold less.

Windows wants me to format the stick

Do not format it; close the window. Windows cannot read the stick because it is now prepared for Linux, which means the writing worked.

Can I use the stick for other things afterwards?

Yes. After installing, format it again in Windows' Disk Management, or with Rufus or Etcher, and use it as before.
