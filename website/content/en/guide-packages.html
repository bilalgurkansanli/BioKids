If your computer already runs Debian 13, you can install BioKids from packages instead of the ISO. This guide needs a little use of a terminal.

Requirements

  • Debian 13 "trixie", amd64. Ubuntu and other distributions are untested and unsupported.
  • An X11 session. Wayland is not supported; biokids-desktop brings Xfce and LightDM with it.
  • At least 4 GB of memory and about 25 GB of disk; 7 GB of memory or more for the optional assistant.
  • An account that can use sudo, and the internet while installing.

If you want the assistant too

Ask Me needs newer versions of llama.cpp and whisper.cpp than Debian 13 ships; they come from the BioKids repository. So biokids-ai cannot be installed on a plain Debian 13 without the BioKids repository added. On the ISO, everything is already in place.

{% call m.callout('warn', 'The assistant comes with the ISO for now') %}

The assistant's runtime joins the APT repository with the next release (2.0.1). Until then biokids-ai cannot be installed this way; for a computer that should have the assistant, follow the ISO install guide.

{% endcall %} {{ m.code('sudo apt install biokids-ai', 'Terminal') }}

Then download the model in the panel and turn it on for a child: Ask Me guide.

Upgrades

BioKids never updates itself. You get updates yourself, together with the rest of Debian. The BioKids packages depend on each other's exact version and are always upgraded together:

{{ m.code('sudo apt update && sudo apt upgrade', 'Terminal') }}

Removing

To remove the packages and keep or delete your family's records: uninstall guide.

Something wrong?

Can I install it on Ubuntu?

Not for now: the repository is for Debian 13 "trixie" only, and Ubuntu is untested. The easiest way is the BioKids ISO, which already contains Debian 13.

biokids-ai will not install; it cannot find llama.cpp-tools.

The newer versions of these packages are not in Debian 13; they come from the BioKids repository. Make sure you added it as in step 2 and ran sudo apt update.

Which version is installed?

It is shown at the bottom of the panel. In a terminal, apt policy biokids tells you too.

The session starts in Wayland.

BioKids runs only on X11. The LightDM and Xfce that come with biokids-desktop already use X11; with another login manager, choose the Xfce (X11) session.
