What to put in a report

To sort it out faster together, tell us:

  • The BioKids version: at the bottom of the panel (e.g. "BioKids {{ site.version }}"). biokids-admin version in a terminal shows it too.
  • The Debian version, and whether it is a real computer or a virtual machine.
  • What you did, what you expected, and what happened, step by step.
  • If useful, the background service's latest log lines:

When will I hear back?

BioKids is an open-source project made by one person in their own time. Every message is read, but a reply can take a few days. For an urgent security problem, follow the route in the security policy.

Contribute

BioKids is open to everyone's help: translations, hardware reports ("everything worked on this computer" is valuable too), bug reports and code. Read the contributing guide first: it explains how work is done and lists the features the project will not accept (covert monitoring, keylogging, screenshots the child is not shown, and the like). Everyone who takes part follows the Code of Conduct.
