This guide installs BioKids as the only system on a computer: nothing else stays on it. Installing needs no network and takes 20–40 minutes on most computers.

{% call m.callout('warn', 'Is there a Windows on it you want to keep?') %}

Then follow install beside Windows instead. The "use entire disk" option this guide picks erases everything on the disk.

{% endcall %}

Before you start

  • Have the BioKids USB stick ready: make a USB stick.
  • A 64-bit computer with at least 4 GB of memory and 25 GB of disk (requirements).
  • Back up anything important on the computer. Plug a laptop in.
  • Think of a password for your own parent account on the computer. Your child should not know it.

After installing

  • When the wizard is done, restart once: only then does your child's picture appear on the login screen.
  • The parent panel is the BioKids Parent Panel icon on your desktop, and in the applications menu.
  • Not in Turkey? The installer sets the time zone to Istanbul. Open a terminal from your own account and set yours (find its name with timedatectl list-timezones):
{{ m.code('sudo timedatectl set-timezone Europe/London') }}

BioKids never updates itself; updates come with Debian's usual updates.

Something wrong?

The USB stick is not in the boot menu

Try another USB port (straight into the computer, not a hub). If "Fast Boot" is on in the computer's settings (BIOS/UEFI), turn it off. If the stick still does not show, write it again with Etcher, or Rufus in DD mode.

The stick is chosen but does not start, or a "Secure Boot" message appears

BioKids uses Debian's signed boot loader, so Secure Boot can stay on with most computers. If yours still refuses, turn Secure Boot off in the computer's settings and try again.

It did not find the Wi-Fi

Installing needs no network, so carry on. The image includes drivers for common Wi-Fi cards; if yours is not recognised, use a cable after installing and fill in the hardware form, and we will sort it out together.

The clock is wrong after installing

Set your own time zone as shown in After installing; the time corrects itself once the computer is online.
