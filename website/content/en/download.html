Check the file you downloaded

To be sure the file is complete and unchanged, compute its SHA256 and compare it with the value in the SHA256SUMS file on the release page. They must match character for character.

Windows

Open PowerShell in the folder with the file and type:

{{ m.code('Get-FileHash .\\' ~ site.iso_name ~ ' -Algorithm SHA256', 'PowerShell') }}

macOS

In Terminal, in the folder with the file:

{{ m.code('shasum -a 256 ' ~ site.iso_name, 'Terminal') }}

Linux

Download SHA256SUMS into the same folder as the ISO and type:

{{ m.code('sha256sum -c --ignore-missing SHA256SUMS', 'Terminal') }}

It should end with OK.

{{ m.code('curl -fsSL ' ~ site.apt_url ~ '/KEY.gpg | gpg --import\ngpg --verify SHA256SUMS.asc SHA256SUMS', 'Terminal') }}

It should say "Good signature" and show the fingerprint above.

What's in the ISO?

  • Debian 13 "trixie" and the Xfce desktop (for the parent; the child never sees it).
  • All of BioKids: the background service, the parent panel, the child's launcher, Zio and Sio.
  • Children's apps: GCompris, Tux Paint, TuxMath, SuperTux and more.
  • The runtime for the Ask Me assistant (llama.cpp, whisper.cpp, Kiwix). The models are not included; you download them from the panel if you want them.
  • Debian's firmware for wireless cards.

The live session on the USB stick is only for trying and installing: the child supervision runs on the installed computer.
