Want to see BioKids before putting it on a real computer? With the free VirtualBox you can make a "virtual computer" inside your own and install BioKids there. Nothing happens to your real disk.

{% call m.callout('note', 'Why not just try the USB stick?') %}

The live session on the stick is for looking at the desktop and installing; BioKids' services are switched off there on purpose. The launcher, the time limits and the panel only run on an installed system. A virtual machine is the easiest way to see that without changing your computer.

{% endcall %}

Before you start

  • VirtualBox 7 from virtualbox.org (free for Windows, Intel Macs and Linux).
  • The BioKids ISO from the download page. No need to write it to a USB stick.
  • At least 8 GB of memory and 45 GB of free disk on your computer.

Create the virtual machine

    {% call m.step('Make a new machine', 'new') %}

    In VirtualBox press Machine → New. Name: BioKids. As the ISO Image, choose the BioKids ISO. Type Linux, version Debian (64-bit).

    {% call m.callout('warn') %}

    Tick Skip Unattended Installation. Otherwise VirtualBox tries to run the installation its own way.

    {% endcall %} {% endcall %} {% call m.step('Set the memory, processors and disk', 'hardware') %}
    Memory4096 MB; 8192 MB or more to try the Ask Me assistant too
    Processors2 or more
    EFIOptional: both EFI and BIOS work
    Hard disk40 GB, dynamically allocated (it grows as it is used)
    {% endcall %} {% call m.step('Set the graphics controller to VBoxSVGA', 'display') %}

    Select the machine and go to Settings → Display. Set the Graphics Controller to VBoxSVGA and raise the video memory to 128 MB. On some computers the screen stays black with VMSVGA.

    {% endcall %}

Install BioKids

    {% call m.step('Start it and choose "Start installer"', 'start') %}

    Press Start. When BioKids' menu appears, choose Start installer. The language, keyboard and parent account are as in the install guide.

    Clicking inside the virtual machine may "capture" the mouse; press the right {{ m.kbd('Ctrl') }} key (the Host key; on a Mac the left {{ m.kbd('⌘') }}) to get it back.

    {% endcall %} {% call m.step('Disk: "use entire disk" is safe here', 'disk') %}

    In the virtual machine you can choose "Guided - use entire disk": what gets erased is only the machine's own 40 GB virtual disk. Your real disk is not touched.

    {% endcall %} {% call m.step('Remove the ISO and restart', 'remove-iso') %}

    When it is done, before restarting, choose Devices → Optical Drives → Remove disk from virtual drive in VirtualBox's menu. Then press Continue.

    {% endcall %} {% call m.step('Finish the wizard and sign in as a child', 'try') %}

    Sign in with your account; the setup wizard opens. Add a test child, restart the virtual machine once when the wizard is done, and click the child's picture on the login screen. Now you see what your child would see.

    {{ m.shot(lang ~ '/launcher', 'The child\'s launcher: big tiles, the minutes left, brightness and open apps at the bottom.', 'The same launcher opens in the virtual machine.', sizes='(min-width: 960px) 760px, 100vw') }} {% endcall %}

Tips

  • Before trying something, press Machine → Take Snapshot; one click brings everything back to that moment.
  • The virtual machine is much faster while its window is in front. The assistant answers noticeably slower in a virtual machine than on a real computer; that is normal.
  • The installer sets the time zone to Istanbul; if you live elsewhere, change it as shown in the install guide.
  • Like it? To install it on a real computer: make a USB stick.

Something wrong?

The screen stays black

Turn the machine off, check that Settings → Display → Graphics Controller is VBoxSVGA, and start it again.

It says "No bootable medium found"

The ISO is not attached. In Settings → Storage, choose the BioKids ISO for the optical drive. If it says this after installing, the installation did not finish; install again.

Everything is very slow

Give it more processors, keep the virtual machine's window in front, and close other heavy programs on your computer.
