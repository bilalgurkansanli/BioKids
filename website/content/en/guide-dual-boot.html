You can install BioKids without erasing Windows: you free some space in Windows, BioKids installs into that space, and the computer asks which one you want at every start. Half the steps happen in Windows, half in the installer.

Before you start

  • Back up your important files (an external disk or the cloud). Changing partitions always carries a small risk.
  • At least 40 GB free on the Windows disk.
  • If BitLocker is used, have the recovery key at hand (in your Microsoft account: aka.ms/myrecoverykey).
  • Plug a laptop in. Have the BioKids USB stick ready: make a USB stick.

Prepare Windows

    {% call m.step('Suspend BitLocker (if it is on)', 'bitlocker') %}

    Open Control Panel → BitLocker Drive Encryption. If BitLocker is on for C:, press Suspend protection, so changing the boot settings does not make Windows ask for the recovery key. Afterwards, press Resume protection in the same place.

    Cannot find that page (for example "Device encryption" on Windows Home)? Write the recovery key down anyway.

    {% endcall %} {% call m.step('Turn off Fast Startup', 'fast-startup') %}

    With Fast Startup on, Windows never fully shuts down and leaves its disk half open. Turn it off: Control Panel → Power Options → Choose what the power buttons do → Change settings that are currently unavailable → untick Turn on fast startup → Save changes.

Install BioKids

    {% call m.step('Start from the stick, in the same mode as Windows', 'boot-stick') %}

    Plug the stick in, restart, and keep tapping the boot menu key (often {{ m.kbd('F12') }}, {{ m.kbd('F11') }}, {{ m.kbd('F9') }}, {{ m.kbd('F8') }} or {{ m.kbd('Esc') }}). If BIOS Mode was UEFI, choose the stick entry starting with "UEFI: …"; if it was Legacy, the one without "UEFI".

    {% call m.illus('The computer\'s boot menu. If Windows is UEFI, choose the stick line starting with "UEFI:".') %}

    Boot Menu

    • Windows Boot Manager
    • UEFI: USB Flash Disk 1.00
    • USB Flash Disk 1.00

    ↑↓ select · Enter boot

    {% endcall %} {% call m.callout('tip', 'Cannot catch the key?') %}

    In Windows: Settings → System → Recovery → Advanced startup → Restart now → Use a device → your USB stick. (UEFI computers only.)

    {% endcall %}

    Secure Boot can stay on: BioKids uses Debian's signed boot loader. If your computer still refuses the stick, turn Secure Boot off in its settings.

    {% endcall %} {% call m.step('"Start installer", language, keyboard and your account', 'installer') %}

    Choose Start installer in BioKids' menu. Choose the language and keyboard and create your parent account (name, username, password). These steps are the same as in the install guide.

    {% endcall %} {% call m.step('Choose "use the largest continuous free space"', 'free-space') %}

    On Partition disks, choose "Guided - use the largest continuous free space". It installs only into the space you freed in Windows: nothing outside that space is touched.

    {% call m.illus('The right option is at the top: the free space. The "use entire disk" options erase Windows.') %}

    {% endcall %} {% call m.callout('danger', 'Do not choose "use entire disk"') %}

    The options that say "entire disk" erase everything on it, Windows included. If you are not sure, press Go Back.

    {% endcall %}

    Accept "All files in one partition", check on the summary that new partitions are made only in the free space, and confirm writing the changes.

    {% endcall %} {% call m.step('Wait, take the stick out, restart', 'finish') %}

    Copying needs no network and takes 20–40 minutes on most computers. When it is done, take the stick out and press Continue.

    {% endcall %} {% call m.step('The boot menu: BioKids or Windows?', 'boot-menu') %}

    From now on the computer shows a menu for 5 seconds at every start. Press nothing and BioKids starts; to go to Windows, choose Windows Boot Manager with the arrows and press {{ m.kbd('Enter') }}.

    {% call m.illus('BioKids\' boot menu. BioKids appears under Debian\'s name, "Debian GNU/Linux".') %}

    {% endcall %}

    When you sign in, the setup wizard opens. Not in Turkey? Set your time zone afterwards, as in the install guide.

    {% endcall %} {% call m.step('Put a password on Windows', 'windows-password') %}

    BioKids does not supervise Windows. Your child could pick Windows in the menu, so give your Windows account a password (or PIN) your child does not know. If you suspended BitLocker, press Resume protection now.

    {% endcall %}

Change your mind later? You can remove BioKids and go back to Windows only: back to Windows.

Something wrong?

Windows is not in the boot menu

Sign in to BioKids with your own account, open a terminal and type the line below; the menu looks for Windows again. If it is still missing, check that you started the stick in the same mode as Windows (UEFI or Legacy).

{{ m.code('sudo update-grub') }}

The computer goes straight to Windows without the menu

Some computers change the boot order on their own. Open the computer's settings (BIOS/UEFI; often {{ m.kbd('F2') }} or {{ m.kbd('Del') }}) and move debian to the top of the Boot Order.

Windows asks for the BitLocker recovery key

That happens because the boot settings changed; nothing is broken. Get the key from your Microsoft account (aka.ms/myrecoverykey) and enter it. After that, Windows starts normally.

Windows' clock is a few hours off

BioKids and Windows read the computer's clock differently. In Windows go to Settings → Time & language → Date & time and press Sync now.
