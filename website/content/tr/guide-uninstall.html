Önce: ailenizin yedeği (isteğe bağlı)

Bir gün yeniden kurabilirseniz panelde Ayarlar → Yedekle ve taşı → Yedeği indir ile çocukların kurallarını ve geçmişini tek bir dosyaya alın ve bir USB belleğe kopyalayın. Dosya aile parolanızla şifrelenir; PIN'ler ve e-posta ayarları içinde yoktur.

BioKids'i kaldırıp Debian'ı tutmak

BioKids, ISO'dan kurulduğunda da Debian'ın üstünde paketler olarak durur. Bu paketleri kaldırınca geriye sıradan bir Debian ve Xfce masaüstü kalır. Kendi hesabınızla girip bir uçbirim açın:

    {% call m.step('Asistanın modellerini silin (kuruluysa)', 'asistan') %}

    Sor Bana'nın birkaç GB'lık modellerini siler.

    {{ m.code('sudo apt purge biokids-ai') }} {% endcall %} {% call m.step('BioKids\'i kaldırın', 'kaldir') %} {{ m.code('sudo apt purge biokids biokids-desktop biokids-core biokids-daemon biokids-panel biokids-shell biokids-voice') }}

    Bir soru gelir: "Bu ailenin BioKids verileri silinsin mi?" Varsayılan yanıt Hayır'dır ve kayıtlar bilgisayarda kalır. Her şeyin silinmesini istiyorsanız Evet deyin: kurallar, geçmiş, ses kayıtları ve indirilen doğal ses gider.

    Bununla açılış menüsü de Debian'ın olağan görünümüne döner.

    {% endcall %} {% call m.step('Çocukların hesaplarını silin (isterseniz)', 'hesaplar') %}

    Çocukların bilgisayardaki hesapları ve dosyaları (çizimleri gibi) bilerek bırakılır. Silmek için her çocuk için bir kez, kendi kullanıcı adıyla:

    {{ m.code('sudo deluser --remove-home elif') }} {% endcall %} {% call m.step('Gereksiz kalanları temizleyin', 'temizle') %} {{ m.code('sudo apt autoremove') }}

    Telefondan erişimi açtıysanız Tailscale da kurulmuştu; artık gerekmiyorsa sudo apt purge tailscale ile kaldırabilirsiniz.

    {% endcall %}

Yalnızca Windows'a dönmek

Bilgisayarda Windows ve BioKids birlikteyse BioKids'in bölümlerini silip yerini Windows'a geri verebilirsiniz. Bunlar BioKids'in değil, Windows'un kendi araçlarıdır; dikkatle ve sırayla yapın.

{% call m.callout('danger', 'Başlamadan önce') %}
  • Önemli dosyalarınızı yedekleyin.
  • BitLocker kullanıyorsanız kurtarma anahtarınız elinizde olsun (aka.ms/myrecoverykey).
  • Sıralamayı değiştirmeyin: önce Windows'u açılışta ilk sıraya alıp denersiniz, sonra bölümleri silersiniz. Ters sırada bilgisayar açılmayabilir.
{% endcall %}
    {% call m.step('Windows\'u açın', 'win-ac') %}

    Açılış menüsünde Windows Boot Manager'ı seçin.

    {% endcall %} {% call m.step('Windows\'u açılışta ilk sıraya alın', 'win-ilk') %}

    Başlat'a cmd yazın, Komut İstemi'ne sağ tıklayıp Yönetici olarak çalıştır'ı seçin ve şunu yazın:

    {{ m.code('bcdedit /set {fwbootmgr} displayorder {bootmgr} /addfirst', 'Komut İstemi (yönetici)') }}

    Bilgisayarı yeniden başlatın: menü çıkmadan doğrudan Windows açılmalı. Açılmazsa devam etmeyin; bilgisayarın ayarlarındaki (BIOS/UEFI) Boot Order'da Windows Boot Manager'ı en üste alın.

    {% call m.callout('note', 'Eski (Legacy/BIOS) kurulumlar') %}

    Windows'un BIOS Modu "Eski" ise bu komut yerine Ayarlar → Sistem → Kurtarma → Gelişmiş başlangıç → Sorun gider → Gelişmiş seçenekler → Komut İstemi'nde bootrec /fixmbr yazın, sonra yeniden başlatıp Windows'un doğrudan açıldığını görün.

    {% endcall %} {% endcall %} {% call m.step('BioKids\'in bölümlerini silin', 'bolumleri-sil') %}

    Başlat düğmesine sağ tıklayıp Disk Yönetimi'ni açın. BioKids'in bölümlerinin sürücü harfi yoktur; boyutlarından tanırsınız: Windows'tan açtığınız alan kadar büyük bir bölüm ve yanında birkaç GB'lık bir takas (swap) bölümü. Her birine sağ tıklayıp Birimi Sil'i seçin.

    {% endcall %} {% call m.callout('warn') %}

    EFI Sistem Bölümü'nü, Kurtarma bölümünü ve C:'yi asla silmeyin. Hangisi olduğundan emin değilseniz durun ve bize yazın.

    {% endcall %} {% endcall %} {% call m.step('C: sürücüsünü büyütün', 'genislet') %}

    C:'ye sağ tıklayın → Birimi Genişlet… → İleri → Son. Boş alan C:'ye katılır.

    Windows bu seçeneği gri gösteriyorsa boş alan C:'nin hemen yanında değildir (ör. arada bir Kurtarma bölümü vardır). O zaman boş alana sağ tıklayıp Yeni Basit Birim ile ayrı bir sürücü (D:) yapabilirsiniz.

    {% endcall %} {% call m.step('EFI\'deki debian klasörünü kaldırın (isteğe bağlı)', 'efi-temizle') %}

    Açılış menüsünde artık kullanılmayan bir "debian" girişi kalmasın isterseniz, yönetici Komut İstemi'nde sırayla yazın. Harfleri dikkatle yazın.

    {{ m.code('mountvol S: /s rd /s /q S:\\EFI\\debian mountvol S: /d', 'Komut İstemi (yönetici)') }} {% endcall %}

Bilgisayarda yalnızca BioKids varsa

İki yolunuz var: yukarıdaki paketleri kaldırma adımlarıyla sıradan bir Debian'a dönmek ya da başka bir sistemi (ör. Windows) kendi USB belleğinden kurmak. İkincisinde o sistemin kurulumu diski siler; önce ailenizin yedeğini ve dosyalarınızı alın.

Sorun mu var?

Silmeden sonra "grub rescue" yazan siyah bir ekran çıkıyor

Bilgisayar hâlâ BioKids'in açılış yükleyicisini arıyor. Bilgisayarın ayarlarına (çoğu zaman {{ m.kbd('F2') }}, {{ m.kbd('F10') }} ya da {{ m.kbd('Del') }}) girin ve Boot Order'da Windows Boot Manager'ı en üste alın. Eski (BIOS) kurulumlarda Windows kurtarma ortamında bootrec /fixmbr çalıştırın.

Ailemin verileri ne olur?

Silinmesini seçmedikçe bilgisayarda kalır. Kaldırma sırasında sorulan soruya Evet derseniz kurallar, geçmiş ve kayıtlar silinir. Bölümleri sildiyseniz zaten hepsi gitmiştir.

Sonra yeniden kurabilir miyim?

Elbette. Kurulumdan sonra panelde Yedekle ve taşı → Geri yükle ile yedeğinizi yüklerseniz çocukların kuralları ve geçmişi geri gelir.
