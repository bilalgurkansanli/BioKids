Windows'u silmeden BioKids kurabilirsiniz: Windows'tan biraz yer açarsınız, BioKids o boş yere kurulur ve bilgisayar her açılışta hangisini istediğinizi sorar. Adımların yarısı Windows'ta, yarısı kurulumda geçer.

Başlamadan önce

  • Önemli dosyalarınızı yedekleyin (harici disk ya da bulut). Disk bölümleriyle oynamak her zaman küçük bir risk taşır.
  • Windows diskinde en az 40 GB boş yer olsun.
  • BitLocker kullanılıyorsa kurtarma anahtarınız elinizin altında olsun (Microsoft hesabınızda: aka.ms/myrecoverykey).
  • Dizüstüyse fişe takın. BioKids USB belleği hazır olsun: USB belleği hazırlama.

Windows'ta hazırlık

    {% call m.step('BitLocker\'ı askıya alın (varsa)', 'bitlocker') %}

    Denetim Masası → BitLocker Sürücü Şifrelemesi'ni açın. C: sürücüsünde BitLocker açıksa Korumayı askıya al'a basın. Böylece bilgisayar açılış ayarları değişince kurtarma anahtarı istemez. Kurulumdan sonra aynı yerden Korumayı sürdür'e basarsınız.

    Bu sayfayı bulamıyorsanız (ör. Windows Home'da "Cihaz şifreleme"), yine de kurtarma anahtarınızı bir kâğıda yazın.

    {% endcall %} {% call m.step('Hızlı Başlatma\'yı kapatın', 'hizli-baslatma') %}

BioKids'i kurun

    {% call m.step('USB bellekten, Windows\'la aynı modda açın', 'bellekten-ac') %}

    Belleği takın, bilgisayarı yeniden başlatın ve açılış menüsü tuşuna art arda basın (çoğu zaman {{ m.kbd('F12') }}, {{ m.kbd('F11') }}, {{ m.kbd('F9') }}, {{ m.kbd('F8') }} ya da {{ m.kbd('Esc') }}). BIOS Modu UEFI ise "UEFI: …" ile başlayan bellek girişini, Eski ise "UEFI" yazmayanı seçin.

    {% call m.illus('Bilgisayarın açılış menüsü. Windows UEFI ise "UEFI:" ile başlayan bellek satırını seçin.') %}

    Boot Menu

    • Windows Boot Manager
    • UEFI: USB Flash Disk 1.00
    • USB Flash Disk 1.00

    ↑↓ seç · Enter başlat

    {% endcall %} {% call m.callout('tip', 'Tuşu yakalayamıyor musunuz?') %}

    Windows'ta Ayarlar → Sistem → Kurtarma → Gelişmiş başlangıç → Şimdi yeniden başlat → Bir cihaz kullan → USB belleğiniz. (Yalnızca UEFI bilgisayarlarda.)

    {% endcall %}

    Secure Boot açık kalabilir: BioKids, Debian'ın imzalı açılış yükleyicisini kullanır. Bilgisayarınız belleği yine de reddederse ayarlardan Secure Boot'u kapatın.

    {% endcall %} {% call m.step('"Start installer", dil, klavye ve hesabınız', 'kurulum-basla') %}

    BioKids menüsünde Start installer'ı seçin. Dili, klavyeyi seçin ve ebeveyn hesabınızı (adınız, kullanıcı adı, parola) oluşturun. Bu adımlar kurulum rehberindeki ile aynıdır.

    {% endcall %} {% call m.step('Boş alanı seçin: "use the largest continuous free space"', 'bos-alan') %}

    Disk bölümleme ekranında en büyük boş alanı kullanan yönlendirmeli seçeneği seçin; İngilizcesi "Guided - use the largest continuous free space". Bu seçenek yalnızca Windows'tan açtığınız boş alana kurar; o alanın dışındaki hiçbir şeye dokunmaz.

    "Entire disk" (tüm disk) yazan seçenekler Windows dahil diskteki her şeyi siler. Emin değilseniz Go Back ile geri dönün.

    {% endcall %}

    "Tüm dosyalar tek bölümde" önerisini kabul edin, özet ekranında yalnızca boş alanda yeni bölümler oluşturulduğunu görün ve değişiklikleri diske yazmayı onaylayın.

    {% endcall %} {% call m.step('Bekleyin, belleği çıkarın, yeniden başlatın', 'bitir') %}

    Kopyalama ağ istemez; çoğu bilgisayarda 20–40 dakika sürer. Bitince belleği çıkarıp Continue'ya basın.

    {% endcall %} {% call m.step('Açılış menüsü: BioKids mi, Windows mu?', 'acilis-menusu') %}

    Artık bilgisayar her açılışta 5 saniye boyunca bir menü gösterir. Hiçbir şeye basmazsanız BioKids açılır; Windows'a geçmek için okla Windows Boot Manager'ı seçip {{ m.kbd('Enter') }}'a basın.

    Giriş yapınca ilk kurulum sihirbazı açılır.

    {% endcall %} {% call m.step('Windows hesabına parola koyun', 'windows-parola') %}

    BioKids Windows'u denetlemez. Çocuğunuz menüden Windows'u seçebilir; bu yüzden Windows hesabınıza çocuğunuzun bilmediği bir parola (ya da PIN) koyun. BitLocker'ı askıya aldıysanız şimdi Korumayı sürdür'e basın.

    {% endcall %}

Fikrinizi değiştirirseniz BioKids'i kaldırıp yalnızca Windows'a dönebilirsiniz: Windows'a geri dönme.

Sorun mu var?

Açılış menüsünde Windows yok

BioKids'e kendi hesabınızla girin, bir uçbirim açın ve aşağıdakini yazın; menü Windows'u yeniden arar. Hâlâ yoksa USB belleği Windows'la aynı modda (UEFI/Eski) açıp açmadığınızı kontrol edin.

{{ m.code('sudo update-grub') }}

Bilgisayar menüyü göstermeden doğrudan Windows'a açılıyor

Bazı bilgisayarlar açılış sırasını kendileri değiştirir. Bilgisayarın ayarlarına (BIOS/UEFI; çoğu zaman {{ m.kbd('F2') }} ya da {{ m.kbd('Del') }}) girin ve Boot Order'da debian girişini en üste alın.

Windows BitLocker kurtarma anahtarı istiyor

Bu, açılış ayarları değiştiği için olur; bir şey bozulmadı. Anahtarı Microsoft hesabınızdan (aka.ms/myrecoverykey) alıp girin. Bir kez girince Windows normal açılır.

Windows'ta saat birkaç saat kaymış

BioKids ve Windows bilgisayarın saatini farklı okur. Windows'ta Ayarlar → Saat ve dil → Tarih ve saat → Şimdi eşitle'ye basın.
