# Getting help

**Setting BioKids up, or using it at home?** The guides are on the website,
[biokids.bilalgurkansanli.com](https://biokids.bilalgurkansanli.com), and the panel's
own **Yardım** page answers the common questions on the computer itself, offline.

**Something does not work as it should?** Open an
[issue](https://github.com/bilalgurkansanli/BioKids/issues/new/choose) with the bug
form. It asks for what helps: the BioKids version (at the bottom of the panel), the
Debian version, and whether the computer is real or a virtual machine.

**BioKids does not work on your hardware** — the screen, the sound, Wi-Fi, the
microphone? The hardware form collects what is needed to fix it.

**A security problem?** Please do not open an issue: report it privately, as
[`SECURITY.md`](SECURITY.md) describes.

Turkish or English, whichever is easier for you. Please never attach anything that
